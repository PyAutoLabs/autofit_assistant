## Conversational chat routes (retired 2026-09-10)

The assistant is supported **only inside an AI coding agent** (Claude Code or Codex; OpenCode as an experimental
alternative). Browser-chat routes were retired because a chat that cannot execute code or read data cannot enforce
the assistant's safeguards — verifying the current PyAutoFit API, inspecting the data before fitting, checking a
fit's outputs, and never silently altering the user's likelihood code.
